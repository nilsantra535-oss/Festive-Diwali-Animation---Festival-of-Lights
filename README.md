# ✨ Festive Diwali Animation - Festival of Lights 🪔

A vibrant, cheerful, and polished Python animation celebrating Diwali built using **Pygame** and **NumPy**.

---

## 🌟 Features

* **Realistic Diyas:** Glowing and flickering oil lamps with dynamic light cast and rising sparks.
* **Spectacular Fireworks:** Multi-stage rocket launches, colorful bursts (Peony, Willow, Ring, Glitter), and spark trails.
* **Sparkler Fountains (Diwali Anar):** Golden cascading sparks erupting from flowerpot fountains.
* **Festive Decor:** Hanging fairy lights, glowing geometric Rangoli floor motifs, and a warm terrace platform.
* **Breathing Greeting:** Elegant golden-glowing "Happy Diwali" banner with smooth pulsing animations.
* **Procedural Sound Engine:** Custom synthesized sound effects (booms, whistles, and crackles) generated in real-time via **NumPy** and **Pygame Mixer** (no external audio files required!).
* **Interactive Controls:** Click anywhere to launch a firework, press **Space** for a grand finale barrage, and toggle settings dynamically.

---

## 🛠️ Requirements & Dependencies

Make sure you have Python installed along with the required libraries:

* Python 3.8+
* `pygame`
* `numpy` (Optional, enables procedural sound effects)
